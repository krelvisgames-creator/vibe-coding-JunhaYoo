동아리 서류 심사 보드

구글폼 응답 CSV와 선발 조건으로 통과·보류·탈락을 나누고, 조건별 근거를 확인합니다.

1 응답 파일 불러오기

구글폼 응답 다운로드(.csv)로 받은 zip을 그대로 넣거나, CSV·엑셀(xlsx·xls·xlsm·ods) 파일을 넣으세요. 파일은 이 브라우저 안에서만 읽고 어디에도 올리지 않습니다.

또는 파일을 이 페이지 아무 곳에나 끌어다 놓으세요

2 문항 역할 고르기

AI를 쓸 때 외부로 보내는 것은 심사 문항의 응답뿐입니다. 성별·나이는 기본으로 심사에 포함되고, 학번은 입학년도 2자리만 보냅니다. 연락처·이메일은 기본으로 제외됩니다. 이름은 화면 표시에만 쓰고 보내지 않습니다. 지원자는 A행번호로만 구분합니다.

3 선발 조건 설정

조건은 지원서 응답으로 확인할 수 있는 한 문장으로 적으세요. 각 조건은 심사 문항 전체를 보고 판단합니다. 조건은 이 브라우저에 자동 저장되고, 다른 CSV를 불러와도 그대로 남습니다.

필수 조건 하나라도 미충족이면 탈락

    결격 조건 하나라도 해당하면 탈락

      우대 조건 기준 개수 이상 충족하면 통과

        개 이상 충족하면 통과 (최대 0개)

        판정 규칙 (위에서부터 먼저 걸리는 규칙 적용)

          아직 판단하지 않은 조건은 '애매'로 계산합니다. 조건 문장을 고치면 그 조건의 판단은 다시 해야 합니다. 최종 결정은 임원이 합니다. 직접 바꾼 판정이 규칙보다 우선하고 수정 표시가 붙습니다.

          AI(Groq 무료 플랜)는 판단이 비어 있는 조건만 채우고, 임원이 누른 판단은 바꾸지 않습니다. 무료 한도(분당 토큰 8,000)에 맞춰 15초 간격으로 한 명씩 보냅니다. 40명이면 10분쯤 걸립니다.

            Groq API 키

            Groq Console에서 무료로 만든 API 키를 넣으세요. 사용 모델:

            • 키는 이 브라우저에만 저장됩니다. 공용 PC에서는 사용 후 꼭 키 삭제를 누르세요.
            • 무료 플랜 한도: 분당 요청 30번, 하루 요청 1,000번, 분당 토큰 8,000개.
            • 보내는 것은 심사 문항 응답(성별·나이 포함, 학번은 입학년도만)뿐이고, 이름·연락처·이메일은 보내지 않습니다. Groq는 요청 내용을 기본적으로 보관하지 않지만, 안정성·악용 감시를 위해 최대 30일까지 보관할 수 있습니다.
